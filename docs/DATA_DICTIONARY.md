# Data Dictionary

| Field | Description |
|---|---|
| Incident ID | Synthetic unique incident identifier |
| Created Date | Date the incident was logged |
| Created Time | Time the incident was logged |
| Priority | P1 to P4 operational priority |
| Category | High-level incident category |
| Subcategory | More specific incident type |
| Service | Business/IT service affected |
| Assignment Group | Team responsible for resolution |
| Department | User's business department |
| Location | Simulated operating location |
| Status | Current incident status |
| Resolution Hours | Synthetic elapsed resolution time |
| SLA Target Hours | Target resolution time based on priority |
| SLA Met | Whether the target was met |
| First Contact Resolution | Whether resolved at first contact |
| Reopened | Whether the incident was reopened |
| Business Impact | Simulated business impact classification |
| Root Cause Type | High-level cause classification |
