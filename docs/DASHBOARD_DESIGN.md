# Dashboard Design

## Executive Overview

### KPI Cards
- Total Incidents
- Open Incidents
- SLA Compliance
- Average MTTR
- First Contact Resolution
- Reopen Rate

### Visuals
1. Monthly incident trend
2. Incidents by priority
3. Incidents by service
4. SLA compliance by service
5. Top incident categories

## Service Performance

Use a matrix or bar chart comparing:

- Service
- Incident volume
- SLA compliance
- Average MTTR
- Reopen rate

## Operational Analysis

Recommended dimensions:

- Assignment Group
- Category
- Subcategory
- Department
- Location
- Priority

## Improvement Opportunities

Create a table identifying:

- SLA breaches
- High MTTR incidents
- Reopened incidents
- Repeated categories
- P1/P2 incidents

This page should help an IT Operations manager move from reporting to action.
